## 1. MCP — текущая работа

- [x] Отдельный Rust-компонент с официальным SDK RMCP 3.4.1, локальный stdio, пять инструментов чтения.
- [x] Управляемый индекс SQLite FTS5; только готовые расшифровки, саммери, карты и разборы выбранных проектов.
- [x] Разрешения по проектам и типам материалов, выключены по умолчанию; повторная проверка каждого запроса, отзыв без перезапуска сервера.
- [x] Панель доступа в Sol Flow на русском и английском, конфигурация Claude Desktop без автоматической записи в настройки клиента.
- [x] Явное сохранение текстовой копии разрешенных материалов; исходное хранилище не меняется.
- [x] Импорт файла/ссылки в выбранный проект на Mac/Windows и Android.
- [x] Обработчик локальных ссылок на запись и время в коде десктопа; не запускает звук автоматически.
- [x] Автотесты изоляции, сохранности оригиналов, прав доступа и реального MCP-обмена на вымышленных встречах.
- [ ] Проверить приложение целиком на Mac, включая обработку ссылки при закрытом и открытом окне, очередь обновления индекса и одновременную синхронизацию.
- [x] Собрать, подписать прежним сертификатом и установить MCP-компонент вместе с приложением на Mac Ивана, проверить нативные разрешения и сохранность записей.

Это позволяет честно отделить отзыв MCP-доступа от уже сохраненных файлов.

## 3. Найденный список качества расшифровок

Источник: `11_Sol_Flow/Качество_расшифровки_заметки_2026-09-23.md`. Это наблюдения и гипотезы, а не уже подтвержденные алгоритмические решения.

- [ ] Границы спикеров внутри фразы: проверить привязку к акустическим паузам, не подменяя атрибуцию ради красивого текста.
- [ ] Частое «несколько голосов»: отличать смену говорящего от одновременной речи; пороги измерить на размеченных примерах.
- [ ] Пустые сегменты и мусор на стыках: скрывать в представлении только после проверки, оригинал сохранять.
- [ ] Словарь проекта для имен/брендов, подсветка смешанной раскладки; предлагаемые замены требуют контроля пользователя.
- [ ] Числа, суммы, время: регрессионные примеры и сохранение исходной формулировки при сомнительной нормализации. Не внедрять слепые замены.
- [ ] Отдельный чистовой режим с сохранением дословной версии.
- [ ] Более читаемые абзацы и частота таймкодов без потери точного перехода к исходной реплике.
