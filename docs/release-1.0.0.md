# Sol Flow 1.0.0

[English](release-1.0.0.en.md)

Проекты Sol Flow можно подключать к ИИ через локальный MCP. Обновление общее для Windows, Mac и Android; сервер работает на компьютере, телефон управляет доступом и синхронизирует материалы.

## Что изменилось

- Доступ к ИИ по проектам и типам материалов: расшифровки, саммери, карты и разборы. По умолчанию доступ выключен.
- Фиолетовое выделение и значок ИИ у разрешённых проектов. На компьютере доступ меняется через панель или правую кнопку мыши; на Android — через панель или удержание проекта.
- Разрешения синхронизируются вместе с проектами. Изменение с одного устройства действует на другом после синхронизации обоих. Старые версии не умеют управлять новыми разрешениями — обновите все устройства.
- На Mac и Windows в комплект входит локальный MCP-компонент для поиска и чтения готовых материалов с названием источника и таймкодами. Отзыв доступа проверяется при каждом новом запросе.
- Кнопка «Скопировать запрос для подключения» формирует инструкции с путями именно этого компьютера. Помощник с доступом к локальным файлам может настроить выбранный клиент. Ручная настройка разделена на команду и отдельные аргументы; полный JSON/TOML предназначен только для файла настроек.
- Обновлённое встроенное руководство на русском и английском, отдельные инструкции и реальные снимки интерфейса Android. Повторное открытие: «О проекте → Руководство по Sol Flow».
- Исправлена проверка путей Windows в MCP, сохранена защита от обхода разрешений через файловые ссылки.

## Подключение

1. На компьютере откройте проект → «Доступ проекта к ИИ». Выберите материалы и нажмите «Подключить проект».
2. Откройте «Подключение клиента и дополнительные действия → Настройка подключения к ИИ» и выберите ChatGPT / Codex, Claude Desktop или другой MCP-клиент.
3. Скопируйте запрос и отправьте помощнику на этом же компьютере. Автонастройка требует доступа помощника к файлам и процессам; обычный чат без такого доступа сможет только объяснить ручные шаги. При необходимости раскройте «Настроить вручную» и копируйте каждое поле отдельно.
4. После настройки и необходимого перезапуска клиента попросите перечислить проекты, прочитать тестовую запись и назвать факт с источником и таймкодом.
5. Отключите доступ и проверьте новый запрос чтения. Ранее полученные ответы остаются в истории чата.

Фиолетовый значок показывает разрешение проекта, а не успешность подключения конкретного клиента. Настройка MCP локальна для компьютера и сама не переносится с Mac на Windows. Android не запускает MCP-сервер. Обычный браузерный ChatGPT/Claude и мобильные чаты требуют отдельного способа подключения; облачный сервер или туннель Sol Flow не устанавливает.

## Данные и ограничения

MCP не размещён на сайте ivansolomin.ru. Компонент работает локально; публичный порт не открывается. Подключённый облачный ИИ обрабатывает запрошенные разрешённые тексты у своего провайдера. Аудио и ключи в MCP-экспорт не входят. Поиск и чтение не изменяют оригиналы; ответы ИИ автоматически обратно в Sol Flow не записываются. Явно сохранённая текстовая копия остаётся на диске после отзыва доступа.

## Скачать и обновить

Файлы выпуска: [Sol Flow 1.0.0](https://github.com/isoloma-ux/solflow/releases/tag/v1.0.0).

- Windows 10/11 x64: `SolFlow_1.0.0_x64-setup.exe`.
- Mac Apple silicon, macOS 14+: `SolFlow_1.0.0_macOS.zip`.
- Android 8+, arm64: `SolFlow_1.0.0.apk` (versionCode 46).

Установите поверх прежней версии, не удаляя данные. Mac и Windows получают предложение через встроенное обновление; Android скачивает APK и запрашивает системное подтверждение установки. Записи, проекты и модели сохраняются. Разрешения микрофона и специальных возможностей проверяются средствами системы, если она попросит их повторно.

Mac подписан прежним собственным сертификатом; нотариального заверения Apple нет. У Windows нет Authenticode-подписи. Подписи пакетов обновления и APK проверяются отдельно и не заменяют доверие магазинов. Выпуск распространяется через GitHub и встроенное обновление, не через App Store или Google Play.

## Проверки и границы

В пилоте проверены локальный MCP, изоляция проектов, отзыв, синхронизация Android ↔ Mac и Claude Desktop с учебными материалами. Пользователь подтвердил установку Windows и работу MCP. Последняя кнопка готового запроса проверена в установленной Mac-сборке и в браузерных проверках RU/EN, включая Windows-пути; самостоятельное выполнение запроса сторонним помощником с чистыми настройками не гарантируется.

Окончательные пакеты публикуются после CI и проверки подписей, версий, состава архивов и манифеста обновления. Физический Huawei, все сценарии конфликтов синхронизации, второй облачный провайдер и чистая установка на всех вариантах Windows отдельно не проверены.
