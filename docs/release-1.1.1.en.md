# Sol Flow 1.1.1

- Six new interface languages: Simplified Chinese, Korean, Japanese, German, French and Spanish. Russian and English remain available. Translations are bundled and work offline.
- Catalog language search works from the first letter, regardless of case. Search localized names, English names or language codes.
- On Mac and Windows, drag the sidebar edge to resize it; the width is remembered. AI badges take up less space.
- On Android, project menus are more compact. AI-enabled projects are also marked in project pickers. Project actions have their own section and icons; deletion is red and requires confirmation.
- Mobile settings and About information are organized into sections.

Changing the interface language does not change speech recognition, recording text or AI permissions. Storage and synchronization formats are unchanged.

This version is shared by Mac, Windows and Android. iPhone remains a separate test application.
