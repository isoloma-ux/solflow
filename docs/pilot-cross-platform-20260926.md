## Как повторить MCP с Claude

1. На компьютере открыть нужный проект, выбрать типы материалов и нажать «Подключить проект». Фиолетовый значок показывает разрешение, а не активный бренд ИИ.
2. «Подключение клиента и дополнительные действия → Настройка подключения к ИИ → Claude Desktop». Скопировать показанный JSON.
3. В Claude Desktop открыть Settings → Developer → Edit Config. Добавить запись в существующий `mcpServers`, сохранив другие настройки и резервную копию файла. Полностью перезапустить Claude.
4. В обычном Chat попросить перечислить проекты, найти тестовую фразу и прочитать источник с названием и таймкодом. Разрешить нужный инструмент.
5. `fetch` принимает **id фрагмента из search**, например `100:transcript:0:0`, а не просто id записи `100`. Поиск лексический; слово «решение» не находит все решения по смыслу.
6. Отозвать доступ в Sol Flow и запросить новое чтение. Старые ответы в истории сохраняются; проверяется результат нового инструмента.

Текущая настройка `solflow-pilot` в Claude указывает на отдельный учебный экспорт. Для реального проекта следует использовать конфигурацию, которую показывает установленный Sol Flow. Локальная конфигурация не подключает веб-версию Claude или мобильное приложение автоматически.

## Windows и публикация исходников

В origin указан push URL `/dev/null`: отправка кода заблокирована локальной настройкой. Подготовлены исходники и workflow `build`, который создает артефакт `SolFlow-Windows-<номер>` без релизного тега. Перед отправкой тестовой ветки требуется согласовать публикацию исходников в GitHub. Не менять защиту молча, не пушить тег и не запускать release.yml.
