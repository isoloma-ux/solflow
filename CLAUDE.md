# Sol Flow — правила разработки

## Паритет платформ (главное правило)

Sol Flow живет на трех платформах: Android (`app-android/`), Mac и Windows
(общий код в `desktop/`). **Любое изменение функциональности делается на
всех трех платформах в одном выпуске.** Прежде чем считать фичу готовой,
проверь: есть ли она на второй кодовой базе, и если нет — реализуй или
явно зафиксируй, почему нельзя.

- Если на какой-то платформе фича невозможна в том же виде (нет API,
  другая модель системы) — это решение записывается словами: в сообщении
  коммита и в списке задач, а не пропускается молча.
- Поведение должно совпадать по смыслу, а не по пикселям: очередь
  расшифровок, пауза записи, экспорт, отмены — одна логика везде,
  интерфейс — родной для платформы.

## Версия и выпуск

- Версия **общая на все три платформы**. Менять разом в трех местах:
  `app-android/app/build.gradle.kts` (versionCode + versionName),
  `desktop/src-tauri/tauri.conf.json`, `desktop/src-tauri/Cargo.toml`
  (после — `cargo update -w`, чтобы обновился Cargo.lock).
- Релиз = пуш тега `vX.Y.Z`: `release.yml` собирает Windows и Mac,
  `android.yml` — APK; всё складывается в один релиз GitHub, манифест
  `latest.json` ведет автообновление внутри приложений.
- Собирать релиз только с зеленого main.

## Окно «Что нового»

- Обновляется на обеих кодовых базах под фактический состав выпуска —
  без «это только на Android»: пользователь Windows читает про свою
  платформу.
- Пункты оформляются **списком с точками**, не абзацами через перенос.
- Android: текст в `whatsnew_body` (values/ и values-en/), показ по
  versionCode в prefs. Десктоп: разметка в `ui/index.html`, показ по
  ключу `версия + WHATSNEW_REV` в localStorage — суффикс поднимается,
  если текст поменялся внутри той же версии.

## Языки

Каждая строка интерфейса живет на двух языках: Android —
`values/strings.xml` + `values-en/strings.xml`; десктоп — русский текст в
разметке/коде + перевод в `ui/i18n.js` (ключ — сама русская строка).

## Осознанные различия платформ

Зафиксированные исключения из паритета (правило: различие — только
записанное словами):

- **Саммери встреч есть только на Mac и Windows.** На телефоне счёт
  4B-модели по длинной расшифровке занимает минуты, вешает интерфейс и
  доводил до перезагрузки (замер пользователя, 2026-09-01). На Android
  остаётся только «Придумать название» (короткий контекст, 4 потока) и
  показ саммери, если оно уже есть у встречи; принести его должна
  синхронизация с десктопом.
