Подключение клиента и дополнительные действия

Клиент ИИ

Разрешение действует для клиентов, подключенных к Sol Flow через MCP. Настройка клиента выполняется отдельно.

Подключить с помощью ИИ

Скопируйте запрос и отправьте помощнику на этом же компьютере. Нужные пути уже внутри.

Помощник сможет настроить подключение, если ему доступна работа с локальными файлами. Без такого доступа он объяснит ручные шаги. Обычный чат в браузере не подключается одним запросом.

Выдано

О проекте

Sol Flow

Распознавание речи и локальные итоги работают на вашем компьютере. Синхронизация и MCP передают выбранные данные только после включения соответствующего доступа.

Кто это делает

Иван Соломин

Директор по маркетингу, не разработчик. Пишу эти приложения, потому что хочу, чтобы людям вокруг было удобнее: расшифровка встреч не должна стоить денег, требовать облака и отдавать чужим серверам голоса коллег.

Sol Flow есть для Mac, Windows и Android — и везде распознавание идет офлайн, на самом устройстве.

Встречи и проекты можно держать одинаковыми на всех устройствах: в настройках подключите Яндекс.Диск или Google Drive, вход по короткому коду. Данные лежат в папке приложения в вашем облаке, чужих серверов нет.

Поддержать

Sol Flow бесплатен и останется таким

Ни подписки, ни рекламы, ни сбора данных. Если приложение пригодилось и хочется сказать спасибо — можно поддержать проект. Это ни на что не влияет: все возможности и так открыты
