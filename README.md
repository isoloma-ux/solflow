# Sol Flow

Офлайновый голосовой ввод для Android. Надиктовал — текст появился в поле ввода
любого приложения. Ничего не уходит в интернет: распознавание идёт на телефоне.

Текущая сборка — **SolFlow-2.1.apk**, стоит на Xiaomi 15.

## Что умеет

- **Плавающая кнопка** поверх других приложений: приходит вместе с клавиатурой,
  тап — диктовка, повторный тап или отпускание при удержании — вставка текста
  прямо в поле ввода.
- **Запись встреч**: часами, в файл на диске, с расшифровкой после остановки и
  таймлайном по времени. Импорт чужих аудиофайлов (mp3, m4a и всё, что умеет
  телефон, с приведением к 16 кГц моно). Экспорт в txt, md, PDF и docx —
  файлы падают в Загрузки.
- **Разделение говорящих** в записи встречи: «говорящий 1/2/…» с разметкой
  по репликам, каждый говорящий своим цветом, тап по имени — переименовать
  (имена уходят и в экспорт). Число людей задается или определяется само. Работает на любом
  языке — модели pyannote + CAM++ через sherpa-onnx сравнивают тембры, а не
  слова. Двухчасовая запись размечается примерно за двадцать минут в фоне.
- **Каталог из 50 моделей** с поиском и выбором языка из 103. Скачивание идёт в
  фоне с уведомлением, несколько моделей одновременно, с отменой.
- **Живой интерфейс**: круглая кнопка записи с пульсом и волной уровня звука,
  мягкие переходы между экранами, каскадное появление списков, нижние листы,
  отклик на каждый тап. Всё гаснет, если в системе выключены анимации;
  проверено на крупном шрифте, в ландшафте и в обеих темах.
- **История расшифровок** по дням.
- **Длинная речь** режется по паузам: ограничение модели в 25 секунд снято.

## Как всё устроено

| Папка | Что это |
|---|---|
| `app-android/` | Приложение: пакет `com.handy.voice` плюс копия Kotlin API sherpa-onnx |
| `tcpp/` | Движок [transcribe.cpp](https://github.com/handy-computer/transcribe.cpp), собирается под arm64 |
| `sherpa-onnx/` | [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) — диаризация; собранные .so лежат в `app-android/app/src/main/jniLibs` |
| `desktop/` | **Sol Flow для Mac** (Tauri 2 + Rust): диктовка по ⌥Пробел с вставкой в активное приложение, каталог моделей с фильтром по языкам, встречи с проектами и экспортом. GigaAM на Metal — 115x realtime. Сборка: `cargo build --release` в `desktop/src-tauri`, готовый бандл — `desktop/Sol Flow.app` |
| `upstream/` | Десктопный [Handy](https://github.com/cjpais/Handy) — источник каталога моделей, в сборку не входит |
| `build-engine-android.sh` | Кросс-компиляция движка под Android |
| `build-catalog.py` | Готовит каталог моделей для приложения |

## Сборка

```bash
. ~/android-toolchain/env.sh
cd app-android && gradle assembleRelease --no-daemon
```

Собирать только release: в debug нативный код компилируется без оптимизации и
работает в 34 раза медленнее.

## Про модели

Основная — **GigaAM v3 e2e-ctc**, русская, 11x быстрее реального времени на
Snapdragon 8 Elite. Замеры показали два неочевидных факта: размер модели не
предсказывает скорость (Parakeet на 463 МБ быстрее Whisper Medium на 481 МБ в
двенадцать раз), а версия F16 быстрее квантованной Q4, потому что движок собран
с поддержкой fp16-инструкций процессора.

## После каждой установки

Android отключает службу специальных возможностей при обновлении приложения.
Без неё текст уходит в буфер обмена вместо поля ввода — включайте заново.

На Xiaomi дополнительно нужны автозапуск и снятие ограничений батареи, иначе
система выгружает приложение и плавающая кнопка пропадает.
