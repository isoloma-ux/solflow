# Sol Flow

**Русский** · [English](README.en.md)

Распознавание речи, которое не покидает ваше устройство. Диктовка в любое
поле ввода и расшифровка встреч — на Mac, Windows и Android. Бесплатно, без
подписки и без отправки звука куда бы то ни было: модели работают прямо на
компьютере или телефоне, интернет нужен один раз, чтобы их скачать.

**Сайт с инструкциями и скриншотами:** [ivansolomin.ru/solflow](https://ivansolomin.ru/solflow)
· **Последняя версия:** [Releases](https://github.com/isoloma-ux/solflow/releases/latest)

## Скачать

Версия общая для всех трех платформ, файлы лежат в последнем релизе.

| Система | Требования | Файл в релизе |
|---|---|---|
| Mac | Apple silicon (M1 и новее), macOS 12 и выше | `SolFlow_X.Y.Z_macOS.zip` |
| Windows | 64-разрядная Windows 10 или 11 | `SolFlow_X.Y.Z_x64-setup.exe` |
| Android | Android 8.0 и выше, 64-разрядный процессор | `SolFlow_X.Y.Z.apk` |

Приложения нет в магазинах и оно не подписано сертификатами Apple и
Microsoft, поэтому при первом запуске система задаст пару вопросов.
Что отвечать и почему — по шагам с картинками на
[странице установки](https://ivansolomin.ru/solflow#install). Коротко:

- **Mac.** Распаковать, перетащить в «Программы», запустить. На окне
  «Sol Flow не открыт» нажать «Готово», затем Системные настройки →
  Конфиденциальность и безопасность → «Все равно открыть». Разрешить
  микрофон и включить Универсальный доступ (без него текст попадает в
  буфер обмена, а не в поле ввода).
- **Windows.** Запустить установщик, в окне SmartScreen нажать «Подробнее» →
  «Выполнить в любом случае». Разрешить микрофон.
- **Android.** Разрешить установку из этого источника, затем Настройки →
  Приложения → Sol Flow → ⋮ → «Разрешить ограниченные настройки», после
  чего включить Sol Flow в специальных возможностях и разрешить показ поверх
  других приложений. На Xiaomi дополнительно — автозапуск и снятие
  ограничений батареи.

После установки откройте раздел «Модели» и скачайте модель для своего
языка. Для русского — GigaAM v3, около 270 МБ. Обновления приложение находит
само и предлагает поставить.

## Что умеет

- **Диктовка в любое приложение.** На компьютере — сочетание клавиш
  (по умолчанию ⌥Пробел на Mac, Ctrl+Пробел на Windows): нажали, сказали,
  текст встал в активное поле. На телефоне — плавающая кнопка, которая
  приходит вместе с клавиатурой. Слова-паразиты можно убирать, отправку
  сообщения — автоматизировать.
- **Встречи.** Запись часами с паузой, расшифровка после остановки с
  разметкой по времени, поиск по всем записям с переходом на нужную реплику.
  Расшифровки идут по очереди, любую работу можно отменить.
- **Говорящие.** Разделение по голосам: приложение сравнивает тембры, а не
  слова, поэтому работает на любом языке. Говорящих можно переименовать,
  имена уходят в экспорт.
- **Конспект и название.** На Mac и Windows локальная языковая модель
  собирает из расшифровки подробный конспект по темам и придумывает записи
  название по содержанию. Модель скачивается один раз по подтверждению,
  на Windows считает видеокарта NVIDIA или AMD.
- **Проекты.** Записи раскладываются по папкам; перетащили запись на
  «+ Проект» — папка создалась.
- **Синхронизация через ваше облако.** Яндекс.Диск или Google Drive на
  выбор, вход по короткому коду; своего сервера у приложения нет. Встречи и
  проекты одинаковы на телефоне и компьютере: телефон записал и расшифровал,
  компьютер посчитал конспект и название и вернул их обратно. Звук
  передается отдельным переключателем.
- **Перевод.** На Mac и Windows расшифровку и саммери можно перевести на
  один из двенадцати языков той же локальной моделью; перевод показывается
  вместо оригинала и уходит в экспорт.
- **Свои записи.** Импорт аудио и видео с диска, расшифровка по ссылке
  (на компьютере — в том числе YouTube и VK через отдельный загрузчик).
- **Экспорт.** txt, markdown, pdf и docx; несколько встреч — отдельными
  файлами или одним; отдельно конспект и звук в wav. На телефоне есть
  системное «Поделиться».
- **Вопрос к записи.** На Mac и Windows под саммери есть поле: «что решили
  по бюджету», «какие сроки назвал Сергей». Отвечает та же локальная
  модель, метки времени в ответе ведут к репликам.
- **Тип записи и разборы.** Модель определяет, что перед ней: встреча,
  вебинар или лекция, интервью или подкаст. Под тип подстраиваются саммери
  и меню «Разобрать»: решения и задачи, письмо по итогам, оглавление с
  таймкодами, тезисы, советы, кейсы и цифры, вопросы и ответы, цитаты,
  о собеседнике, глоссарий, пересказ для поста.
- **Каталог моделей.** Полсотни моделей на сто с лишним языков с поиском и
  фильтром по языку; скачивание в фоне, несколько сразу, с отменой.
- **Обновления.** Приложение проверяет новую версию, сообщает уведомлением
  и ставит ее само.

## Как пользоваться

**Диктовка.** Поставьте курсор в любое поле, нажмите сочетание (или кнопку
на телефоне), говорите. Короткое нажатие включает запись до следующего
нажатия, удержание — запись на время удержания. Текст вставляется сам;
история диктовок хранится в приложении, при желании — вместе со звуком.

**Встреча.** Вкладка «Встречи» → кнопка записи. Можно поставить на паузу,
на Android — из шторки уведомлений. После остановки расшифровка запускается
сама; в открытой встрече — говорящие, конспект, поиск по тексту, экспорт.

**Модели.** Несколько моделей могут лежать рядом, переключение — секунды.
На телефонах с Qualcomm и Samsung берите вариант F16: он быстрее сжатого
Q4, потому что процессор считает fp16 напрямую.

**Синхронизация.** Настройки → «Подключить» Яндекс.Диск: код входа сразу в
буфере обмена, три шага в одном окне. Данные лежат в папке приложения на
вашем Диске, обмен идет напрямую между вашими устройствами и Диском.

## Про модели

Основная для русского — **GigaAM v3 e2e-ctc** (Sber): на Xiaomi 15 в
двадцать раз быстрее реального времени, на Apple silicon с Metal — больше
ста. Для английского — Parakeet TDT 0.6B, для двух десятков европейских
языков — Parakeet v3 и Canary 1B v2, для редких — Whisper (медленнее). Все
модели GGUF для [transcribe.cpp](https://github.com/handy-computer/transcribe.cpp),
каталог унаследован от [Handy](https://github.com/cjpais/Handy).

Замерено по дороге: размер модели не предсказывает скорость (Parakeet на
463 МБ в двенадцать раз быстрее Whisper Medium на 481 МБ), а версия F16
на телефоне быстрее квантованной Q4.

## Как устроен репозиторий

| Папка | Что это |
|---|---|
| `app-android/` | Приложение для Android: Kotlin, пакет `com.handy.voice`, движок через JNI |
| `desktop/` | Приложение для Mac и Windows: Tauri 2 + Rust, интерфейс на HTML/CSS/JS без сборщиков |
| `desktop/src-tauri/src/sync/` | Протокол синхронизации через Яндекс.Диск (повторен в `SyncEngine.kt`) |
| `tcpp/` | [transcribe.cpp](https://github.com/handy-computer/transcribe.cpp) — движок распознавания, собирается под arm64 |
| `sherpa-onnx/` | [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) — разделение говорящих |
| `llama.cpp/`, `desktop/src-tauri/llama-shim/` | Локальная языковая модель для конспектов (только десктоп) |
| `build-catalog.py` | Готовит каталог моделей для приложений |
| `.github/workflows/` | Проверки на каждый push и сборка релиза по тегу |

Правила разработки, в том числе главное — паритет платформ, — в
[CLAUDE.md](CLAUDE.md).

## Сборка

**Android** (нужны JDK 17, Android SDK с NDK и cmake, окружение — в
`~/android-toolchain/env.sh` на машине автора):

```bash
cd app-android && gradle assembleRelease --no-daemon
```

Собирать только release: в debug нативный код компилируется без
оптимизаций и работает в десятки раз медленнее.

**Mac и Windows** (Rust, `@tauri-apps/cli`; на Mac — Xcode command line
tools, на Windows — Vulkan SDK для счета конспекта на видеокарте):

```bash
cd desktop/src-tauri && cargo tauri build
```

Полный список шагов, включая сборку sherpa-onnx и библиотеки для
конспектов, — в `.github/workflows/release.yml`: релиз собирается ровно так.

**Релиз** — пуш тега `vX.Y.Z`: CI собирает Windows, Mac и APK, складывает
все в один релиз GitHub и обновляет манифест `latest.json`, по которому
приложения обновляются сами.

## Осознанные различия платформ

- Конспект и автоназвания считает только десктоп: языковая модель на
  телефоне слишком тяжела. Телефон получает их через синхронизацию.
- «Поделиться» есть только на Android, на компьютере — экспорт в файл.
- Расшифровка YouTube и VK — только на компьютере (нужен yt-dlp).

## На чем основано

- [Handy](https://github.com/cjpais/Handy) (cjpais) — идея, каталог моделей
  и логика очистки текста.
- [transcribe.cpp](https://github.com/handy-computer/transcribe.cpp) —
  распознавание; [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) —
  говорящие; [llama.cpp](https://github.com/ggml-org/llama.cpp) — конспекты.
- Модели GigaAM (Sber), Parakeet и Canary (NVIDIA), Whisper (OpenAI).
